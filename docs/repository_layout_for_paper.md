# Repository Layout For The Final Paper

This repository is organised as the companion repo for `paper/Tractatus_final.docx`.
The current paper path is deliberately narrow: use the retained bilingual data,
the Phase 1-4 validation outputs, the manuscript figure/table manifests, and the
safe non-training reproduction wrapper.

## Top-Level Purposes

`paper/`
: Manuscript-facing material. This includes `paper/Tractatus_final.docx`, TeX
  sources where retained, manuscript figures in `paper/figures/`, and table-ready
  exports in `paper/tables/`.

`tractatus_structure_latents/`
: Current source package and retained source data. The canonical corpus data live
  under `tractatus_structure_latents/data/`.

`tools/`
: Current reproducibility and validation entry points. The safe default command
  is `python3 tools/reproduce_final_paper_outputs.py --dry-run`.

`results/dsh_validation/`
: Canonical empirical evidence for Tractatus_final.docx. Phase 1-4 outputs,
  canonical report exports, verification JSON/Markdown, and the validation
  bundle live here.

`docs/`
: Reader-facing documentation for data, model, experiments, results, and
  reproduction.

`tests/`
: Narrow reproducibility, manifest, and canonical-evidence checks.

## Status Labels

`canonical_evidence`
: Retained empirical evidence used directly by the final paper.

`derived_paper_output`
: Reproducible figure, table, report, bundle, or manifest derived from retained
  evidence.

`audit_only`
: Repository-audit or release-readiness record. Useful for provenance of the
  cleanup process, but not cited as empirical evidence.

`source_data`
: Retained input data needed to reproduce or verify canonical evidence.

`manuscript`
: The final paper document and retained manuscript source files.

`smoke`
: Short development output for command testing only. Not manuscript evidence.

`scratch`
: Local experimental work that is outside the paper companion path.

## Retained Evidence Versus Reproducible Derivatives

Retained evidence:

- `tractatus_structure_latents/data/*.json`
- `results/dsh_validation/phase1_ablations/`
- `results/dsh_validation/phase2_family_holdout/`
- `results/dsh_validation/phase3_controlled_alignment/` paired-batch canonical
  outputs only
- `results/dsh_validation/phase4_case_studies/`
- `results/dsh_validation/canonical_verification.json`
- `results/dsh_validation/CANONICAL_VERIFICATION_REPORT.md`

Reproducible derivatives:

- `paper/figures/`
- `paper/tables/`
- `results/dsh_validation/canonical_reports/`
- `results/dsh_validation/dsh_validation_bundle/` when generated locally
- `results/dsh_validation/dsh_validation_bundle.zip` when generated locally

The generated bundle paths, checkpoints, raw parquet outputs, and smoke outputs
are external release/archive artifacts rather than canonical Git-tracked files.
Their hashes are tracked in `docs/heavy_artifacts_manifest.csv`.
- `paper/final_paper_manifest.csv`

Removed/noncanonical material must not be regenerated by default commands and
must not be cited as evidence for `Tractatus_final.docx`.

## Manuscript Figures And Tables

Manuscript figure paths are governed by:

- `paper/figures/figure_manifest.csv`
- `tools/validate_paper_figure_manifest.py`

Table-ready source exports are governed by:

- `paper/tables/table_manifest.csv`
- `tools/export_paper_tables.py`
- `tests/test_paper_tables.py`

Figures not marked as used by `Tractatus_final.docx` are deletion candidates and
should not be retained as manuscript-facing figures.

## Validation Reports

Canonical validation outputs live under `results/dsh_validation/`.

## Git Ignore Policy

Ignore local clutter only:

- `__pycache__/`
- `*.py[cod]`
- `.pytest_cache/`
- `.idea/`
- `.vscode/`
- `.DS_Store`
- `*.tmp`
- `*.bak`
- `~$*.docx`
- `tmp/`
- `scratch/`

Do not broadly ignore `results/`, `paper/figures/`, `paper/tables/`, or
`paper/Tractatus_final.docx`.

## Non-Destructive Migration Checklist

1. Keep `paper/Tractatus_final.docx` and current manuscript source files under
   `paper/`.
2. Keep only manuscript-used figures under `paper/figures/`; validate with
   `python3 tools/validate_paper_figure_manifest.py`.
3. Keep table-ready exports under `paper/tables/`; validate with
   `python3 -m unittest tests/test_paper_tables.py`.
4. Keep canonical Phase 1-4 evidence under `results/dsh_validation/`; rebuild
   derived reports with `python3 tools/build_canonical_reports.py`.
5. Rebuild the final-paper manifest after generated outputs change:
   `python3 tools/build_final_paper_manifest.py`.
6. Verify the current paper path:
   `python3 tools/reproduce_final_paper_outputs.py --dry-run`,
   `python3 tools/verify_canonical_evidence.py`, and targeted tests.
7. Delete removed/noncanonical producers and stale generated outputs only in
   explicit cleanup commits, so review can distinguish evidence retention from
   repository simplification.
